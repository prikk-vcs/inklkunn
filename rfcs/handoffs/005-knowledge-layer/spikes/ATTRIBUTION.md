# Attribution (spike C, RFC 005 part 1)

The measurements of this spike were made on **revision histories of** the Wikipedia articles below, which are
available under the [Creative Commons Attribution-ShareAlike 4.0 licence](https://creativecommons.org/licenses/by-sa/4.0/)
(CC BY-SA 4.0). Each article's authors are credited in its page history at the address given. **No article text
and no editor identity is kept in this repository**: it holds revision numbers (`revisions.txt`), the measurements
made on them, and the labels by item number. The text was read at run time through the public API and kept only in
a cache outside the repository.
