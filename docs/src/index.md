# inklkunn

**A wiki engine whose storage is a patch-theoretic version-control system, built so that participation
starts with a proposal.** The name is Norwegian: "inclusive" + "knowledge".

This book holds the design set. Read the [project charter](inklkunn-00-project-charter.md) first for the
background, the goals and who decides what, then the [requirements specification](inklkunn-01-requirements-spec.md),
the contract every design must satisfy. The roadmap and milestones are in the repository's `ROADMAP.md`;
the design records are under `rfcs/`; where the project stands right now is `docs/STATUS.md`.

User documentation (features, tutorials, the API reference) is added here as the milestones ship.
